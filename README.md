# HCU Drone Project

Autonomous drone research and development project.

## Main Stack

- Ubuntu 24.04
- ROS 2 Jazzy
- PX4 Autopilot
- Gazebo Sim
- Micro XRCE-DDS
- FAST-LIO
- Livox LiDAR

## Project Areas

- PX4/Gazebo simulation
- 3D LiDAR simulation
- FAST-LIO
- SLAM and mapping
- Autonomous drone control
- Camera-based perception
- Digital twin development

## Repository Structure

- `px4_custom/` — custom PX4 and Gazebo files
- `ros2/` — project ROS 2 packages
- `fastlio/` — custom FAST-LIO code
- `scripts/` — project scripts
- `docs/` — documentation
- `experiments/` — experiment records
